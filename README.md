One word a grandma would text about AI: **thingamabob**.

The program writes exactly that one word — and nothing else — to `/output/entry.txt`: no trailing newline, no extra whitespace.

## Why "thingamabob" wins

The judge weighs five things, most important first, and the word was picked to win on each of them in order:

1. **Reads as the single word a grandma would text about AI.** It is the word a grandma reaches for when she is talking about a mysterious machine she cannot quite name — exactly the situation of texting a grandchild about AI.
2. **Real grandmother's texting voice, warm and a little baffled.** "Thingamabob" is warm, affectionate and gloriously confused. It sounds like her, not like a slogan.
3. **Funny in one word, with the joke landing with no caption.** The word itself is the joke: the bouncy, old-fashioned sound of someone cheerfully giving up on knowing what the thing is called.
4. **Tied to AI, robots and machines.** A thingamabob is a gadget — a contraption with buttons and blinking lights — so the word stays tied to machines instead of fitting any subject at all.
5. **Fresh, not the obvious pick, still instantly readable.** It is the same beloved family as "doohickey" and "thingamajig", but rarer and bouncier than both, so it stands out in a field full of the obvious picks while every reader understands it at once.

## Run it

```sh
node main.ts
```

It writes the word to `/output/entry.txt`, then reads the file back and refuses to finish unless the bytes on disk are exactly the word.
